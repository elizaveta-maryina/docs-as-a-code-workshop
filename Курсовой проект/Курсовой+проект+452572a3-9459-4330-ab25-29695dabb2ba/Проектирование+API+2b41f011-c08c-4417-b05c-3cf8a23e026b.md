# endpoints

## GET /api/orders

### Назначение

Получить список заказов для экрана /orders.

### Query params

```JSON
{
  "from": "string(date) optional",
  "to": "string(date) optional",
  "channelId": "string optional",
  "status": "string(enum OrderStatus) optional",
  "q": "string optional",
  "page": "integer optional",
  "pageSize": "integer optional"
}
```

### Пример запроса

`GET /api/orders?from=2026-04-01&to=2026-04-16&channelId=ch_01&status=PACKED&q=Иванов&page=1&pageSize=20`

### Ответ

```JSON
{
  "items": [
    {
      "id": "ord_9f8c1d2",
      "number": "A-2026-000123",
      "createdAt": "2026-04-16T12:30:00Z",
      "updatedAt": "2026-04-16T13:10:00Z",
      "channelId": "ch_01",
      "customerId": "cust_01",
      "totalAmount": 1990.0,
      "currency": "RUB",
      "fulfillmentMethod": "DELIVERY",
      "deliveryAddress": "Казань, ул. Красная, 1",
      "currentStatus": "PACKED",
      "statusSource": "SYSTEM",
      "statusChangedAt": "2026-04-16T13:05:00Z",
      "hasSyncIssue": false,
      "hasStatusConflict": true,
      "needsAttention": true
    }
  ],
  "page": 1,
  "pageSize": 20,
  "totalItems": 1,
  "totalPages": 1
}
```

## PATCH /api/channels/{channelId}/status

### Назначение

### Path params

```JSON
{ "channelId": "string required" }
```


### Ответ

```JSON

  "id": "ch_01",
  "enabled": false,
  "state": "DISABLED"
}
```
