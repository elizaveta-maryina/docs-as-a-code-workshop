# Единый центр управления заказами

Документация к курсовому проекту **«Система сбора, обработки и синхронизации статусов заказов малого бизнеса между каналами продаж»**.

## Что делает система

- собирает заказы из разных каналов продаж в один реестр
- синхронизирует статусы заказов между каналами и системой (в пределах возможностей канала)
- помогает контролировать обработку заказов и снижать ручную работу

## Навигация по документации

- **Концепция и границы** — что за продукт, для кого и зачем
- **Требования** — FR/NFR и материалы по сбору требований
- **UI** — wireframes и роутинг экранов
- **Бизнес-процессы** — BPMN/DMN для синхронизации статусов
- **API** — OpenAPI спецификация
- **Данные** — ERD: концептуальная, логическая и физическая модели
